## 🐍 Network Reachability Checker

A Python-based networking project that simulates **OSPF path calculation using Dijkstra's Algorithm**.

### Key Areas

- Python
- Dijkstra's Algorithm
- OSPF Concepts
- Weighted Graphs
- Network Path Calculation
- Network Automation

### Practical Work

- Developed a Python-based network reachability checker.
- Represented network topology as a weighted graph.
- Represented routers as nodes and network links as configurable costs.
- Implemented Dijkstra's algorithm to calculate the lowest-cost path.
- Used Python's `heapq` priority queue.
- Simulated OSPF path calculation.
- Demonstrated shortest-path calculation and basic network automation.

### Example

Calculated the lowest-cost path between:

`Router_A → Router_D`

based on the configured topology and link costs.
